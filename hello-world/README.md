# Hello World

A minimal static web page that displays "Hello, World!" as a centered heading on a light background.

This project is self-contained and independent of the STIG Assist app in the rest of the repository.

## How to open

No build step or server is required. Just open the HTML file in any web browser:

- Double-click `index.html`, or
- Open your browser and use **File → Open**, then select `index.html`.
